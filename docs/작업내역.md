### v1.3.1 패킷 최적화: 차단 패킷 기록 + 가족 연결 통신 줄이기
- 차단된 앱이 접속하려던 곳 기록 (B1)
  - 차단 VPN이 패킷 머리만 읽어 목적지 IP·포트, DNS로 물어본 도메인을 기록
  - "통신 감시" 탭 카드와 증거 ZIP `blocked-traffic.csv`에 들어감
- 차단 VPN에 TUN 안쪽 DNS 주소(`10.111.0.1`, `fd00:7068:6973::1`) 지정
  - 지정하지 않으면 차단 앱의 도메인 조회가 VPN 밖 회선으로 나가 이름이 안 잡혔음
- 반복 시도는 한 줄로 합치고 저장은 30초마다 묶어서 함 (B2)
- 가족 연결 통신 줄이기
  - A1: 상시 서비스가 돌면 15분 주기 작업은 동기화 생략
  - A2: 공유 OkHttp로 연결 재사용, 알림 여러 개는 한 요청(`alerts`)으로 묶음
  - A3: 서버가 부모 WebSocket의 ping 자동 응답 시각(`getWebSocketAutoResponseTimestamp`)으로 생존 판단. 생존 신호 HTTP는 내용이 바뀌었거나 실시간 연결이 없을 때, 아니면 12시간에 한 번
  - A4: ping 간격 자동 조절. 45초 시작, 안정적이면 두 배씩 늘려 최대 4분, pong이 없으면 절반
- 핵심 파일
  - `net/PacketParser.kt`, `net/BlockedTraffic.kt`, `net/MonitorVpnService.kt`, `net/MonitorScreen.kt`, `remove/EvidenceExporter.kt`
  - `family/KeepAlivePolicy.kt`, `family/FamilyApi.kt`, `family/FamilyReporter.kt`, `family/FamilyServices.kt`
  - `server/family/src/index.js`
- 검증
  - 단위 테스트 111개 통과 (패킷 파서 무작위 입력 5000개 포함)
  - 서버 e2e(알림 묶음, ping만으로 생존 갱신, 기존 승인·명령) 실서버 ALL PASS
  - 에뮬레이터에서 크롬을 차단하고 확인: `rkowmghx.com` 30회, `c2-server-test5.example.com` 70회, `www.coupang.com` 25회 기록, 증거 ZIP에 CSV 포함
  - 회귀: 연결 → 결정 → 잠금 정상
- 측정: Cloudflare WebSocket은 ping 없이 15분 동안 끊기지 않음 (PC 회선, 연결 3개)
- 한계
  - 여러 앱을 동시에 차단하면 어느 앱의 시도인지 구분 못 함 (그때 차단 중이던 앱 목록만 기록)
  - 통신사 NAT 유휴 시간과 실제 배터리 절감은 실기기에서 미측정
- 다른 세션의 미커밋 "부모 폰 오프라인 알림" 변경은 `git stash`(`stash@{0}`)로 보관 (사용자 결정)

### v1.3.0 자녀 폰이 결정하는 잠금·차단 + 연결 승인 단계
- 연결 승인: 부모 폰이 PIN을 넣으면 자녀 폰에 [승인/거절] 카드가 뜨고, 승인해야 연결됨
  - 거절된 폰은 같은 비밀값으로 다시 요청할 수 없음
  - 승인 전인 부모가 끊으면 자기 요청만 취소
- 결정 요청: 다음 경우 자녀 폰에 [1시간 잠금 / 인터넷만 차단 / 무시]를 물음
  - 위험 점수가 기준 이상 (기준은 100~150, 기본 150, 부모 폰 가족 탭에서 조절)
  - 또는 50점 넘게 급상승해 100점 이상
- 30분 무응답이면 그 앱과 텔레그램(`org.telegram.messenger`, `org.thunderdog.challegram`)·LINE(`jp.naver.line.android`) 인터넷만 자동 차단. 잠금은 자녀만 결정
- 1시간 잠금 화면 ("다른 앱 위에 그리기" 창)
  - 문구: "⚠ 보이스피싱 의심 · 주변의 가족이나 아는 사람에게 이 화면을 보여 주고 직접 설치했는지 물어보세요"
  - 동작: 남은 시간 표시, 112 버튼(전화 걸 1분만 비켜 줌), 통화 중·전화 올 때는 숨김, 재부팅·강제 종료 뒤 복원
  - 끝나면 의심 앱·메신저 삭제 정리 화면
- 잠금 순서: 잠금 창을 먼저 그린 뒤 차단 VPN 시작 (Android 15 백그라운드 포그라운드 서비스 시작 예외 조건) → 증거 ZIP 저장
- 안전장치
  - 명령은 부모 폰이 올린 열린 결정 요청과 requestId·패키지가 맞을 때만 실행
  - 앱 이름은 부모 폰에서 직접 읽음
  - 이 앱·시스템 앱은 대상에서 제외, 2시간 지난 명령은 무시
  - 명령은 도착 순서대로 하나씩 처리
- 서버: 부모 폰도 WebSocket으로 승인·명령을 받음. 같은 결정의 명령·결정 요청은 중복 제거
- 핵심 파일
  - `guard/GuardPolicy.kt`, `guard/GuardController.kt`, `guard/CommandExecutor.kt`, `guard/LockOverlay.kt`, `guard/CleanupScreen.kt`
  - `family/FamilyServices.kt`(공용 `FamilySocket`), `server/family/src/index.js`
- 검증

  - 서버 승인·명령 e2e 실서버 ALL PASS
  - 에뮬레이터 확인 항목

### v1.2.9 가족 연결 (자녀 폰 PIN → 부모 폰 위험 알림 실시간 수신)
- 서버: Cloudflare Worker + Durable Objects (`server/family`), 배포 주소 `https://phishguard-family.hicom15.workers.dev`
- PIN 규칙
  - 10분·1회용, 새 PIN을 받으면 이전 PIN은 무효
  - IP(IPv6는 /64)당 실패·생성 횟수 제한
- 부모 폰 → 자녀 폰
  - 상시 서비스가 앱 설치를 즉시 감지해 위험 중간 이상·원격조종 앱 알림
  - 연결 직후 위험 앱 목록, 3시간마다 생존 신호
- 자녀 폰
  - WebSocket 상시 연결 (ping/pong, 재연결 백오프, 놓친 사건 따라잡기)
  - 하루 넘게 신호가 없으면 경고
- 보내는 정보: 앱 이름·패키지·위험도·근거·생존 신호만. 전화번호·연락처·통화기록·문자·위치는 안 보냄
- 토큰은 클라우드 백업·기기 이전에서 제외 (`res/xml/data_extraction_rules.xml`)
- 검증
  - 실서버 e2e 통과
  - 에뮬레이터 확인: 가짜 악성앱 설치 뒤 자녀 쪽 알림 1초 이내, 끊김 알림
  - 리뷰 지적 17건 반영
- 증거 폰(어머니 폰)은 인터넷이 없어 실기기 연결 테스트는 안 함 (악성앱 통신 방지)
