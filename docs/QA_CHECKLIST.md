# 실기기 QA 체크리스트

실제 휴대폰(Android 8.0 이상, 가능하면 Android 13 이상 1대 포함)에서 확인한다. 항목마다 순서대로 하고, 맞으면 체크한다.
준비물: 검사할 설치 파일 `testmalware.apk`(테스트용 가짜 악성 앱), 설치할 APK, USB 케이블 또는 파일 전송 수단.

기기 정보: 모델 ______ / Android 버전 ______ / 앱 버전 ______ / 확인 날짜 ______

## 1. 설치와 처음 실행 안내

- [ ] **설치**
  - 방법: 릴리스 APK를 내려받아 설치한다. 출처를 알 수 없는 앱 허용 안내가 나오면 허용한다.
  - 기대 결과: 설치가 끝나고 앱 아이콘이 보인다.
- [ ] **안내 1쪽 "급하면 먼저"**
  - 방법: 앱을 처음 연다.
  - 기대 결과: 비행기 모드, 112, 금감원 1332, KISA 118 안내와 전화 버튼 3개가 보인다. 버튼을 누르면 전화 앱이 해당 번호로 열린다(실제로 걸지 말고 돌아온다). 아래에 점 3개와 "다음", "건너뛰기" 버튼이 있다.
- [ ] **안내 2쪽 "이 앱이 하는 일"**
  - 방법: "다음"을 누른다.
  - 기대 결과: 검사, 증거 저장, 인터넷 차단, 삭제, 기록 설명이 보이고, 검사는 인터넷 없이 되며 개인정보를 보내지 않는다는 문장이 있다.
- [ ] **안내 3쪽 "필요한 권한"**
  - 방법: "다음"을 누른다.
  - 기대 결과: 알림, 사용 정보 접근, VPN 설명이 보인다. Android 13 이상에서는 "알림 권한 허용하기" 버튼이 있고, 누르면 시스템 알림 허용 창이 뜬다. 허용하면 버튼이 "알림 권한이 허용되었습니다." 문장으로 바뀐다. 버튼은 "이전", "시작하기"로 바뀐다.
- [ ] **안내는 한 번만**
  - 방법: "시작하기"를 누른 뒤 앱을 완전히 종료하고 다시 연다.
  - 기대 결과: 안내 없이 바로 검사 화면이 열린다.
- [ ] **건너뛰기**
  - 방법: 앱 데이터를 지우고(설정 > 앱 > 저장공간) 다시 열어 1쪽에서 "건너뛰기"를 누른다.
  - 기대 결과: 바로 검사 화면이 열리고, 다시 열어도 안내가 나오지 않는다.

## 2. 검사 결과와 신뢰 앱

- [ ] **검사 실행**
  - 방법: 검사 탭에서 검사를 시작한다.
  - 기대 결과: 설치된 앱이 위험도 순으로 나열되고, 위험도 배지와 점수가 보인다. 비행기 모드에서도 검사가 된다.
- [ ] **앱 상세**
  - 방법: 목록에서 앱 하나를 누른다.
  - 기대 결과: 점수 근거와 허용된 위험 권한이 보이고, 뒤로 가기가 동작한다.
- [ ] **신뢰 앱 지정과 해제**
  - 방법: 위험도가 낮거나 중간인 앱 하나를 신뢰 앱으로 지정한다. 앱을 다시 검사한다. 이후 신뢰 지정을 해제한다.
  - 기대 결과: 지정하면 목록에서 신뢰 표시가 되거나 위험 목록에서 빠진다. 해제하면 원래대로 돌아온다. 앱을 종료했다 다시 열어도 유지된다.

## 3. 기본 전화/문자 앱 탈취 탐지

- [ ] **testmalware 설치 후 탐지**
  - 방법: testmalware를 설치하고 기본 전화 앱과 기본 문자 앱으로 지정해 본다(설정 > 앱 > 기본 앱). 이 앱에서 다시 검사한다.
  - 기대 결과: testmalware가 위험도 높음으로 나오고, 기본 전화/문자 앱을 가로챘다는 근거가 상세 화면에 표시된다.
- [ ] **원래 앱 복원 후 확인**
  - 방법: 기본 앱을 원래 전화/문자 앱으로 되돌리고 다시 검사한다.
  - 기대 결과: 가로챔 근거가 사라지거나 점수가 내려간다.

## 4. 증거 ZIP 저장

- [ ] **ZIP만 저장**
  - 방법: testmalware 상세 화면 또는 삭제 흐름에서 증거 저장을 누른다.
  - 기대 결과: 다운로드 폴더에 ZIP 파일 하나만 생기고(풀린 폴더나 별도 APK 파일은 없음), 저장 완료 안내가 보인다.
- [ ] **ZIP 내용**
  - 방법: 파일 앱 또는 PC에서 ZIP을 연다.
  - 기대 결과: `apk/base.apk`와 `manifest-sha256.txt`가 들어 있다.
- [ ] **해시 일치**
  - 방법: PC에서 `apk/base.apk`의 SHA-256을 계산해 `manifest-sha256.txt`의 값과 비교한다(PowerShell: `Get-FileHash apk\base.apk`).
  - 기대 결과: 값이 같다.

## 5. 삭제 5단계 (testmalware)

- [ ] **1단계 준비**
  - 방법: testmalware 상세 화면에서 삭제를 시작한다.
  - 기대 결과: 5단계 진행 표시가 보이고 현재 단계가 강조된다.
- [ ] **2단계 증거 저장**
  - 방법: 증거 저장을 하거나 건너뛴다.
  - 기대 결과: 저장하면 완료 표시가 되고 다음 단계로 넘어갈 수 있다.
- [ ] **3단계 권한 해제**
  - 방법: 안내에 따라 기기 관리자, 접근성, 알림 접근 등 켜져 있는 권한을 설정 화면에서 끈다.
  - 기대 결과: 끈 항목은 완료로 표시되고, 남아 있으면 삭제가 실패할 수 있다는 경고가 보인다.
- [ ] **Android 13 이상 "제한된 설정 허용"**
  - 방법: Android 13 이상에서 외부에서 설치한 testmalware의 접근성 설정이 회색으로 막혀 있으면, 앱 정보 화면 오른쪽 위 더보기(점 3개)에서 "제한된 설정 허용"을 누르고 다시 권한 화면으로 간다.
  - 기대 결과: 앱 안의 안내가 이 절차를 설명하고, 허용 후 권한을 끌 수 있다.
- [ ] **4단계 삭제**
  - 방법: 삭제 버튼을 눌러 시스템 삭제 확인 창에서 확인한다.
  - 기대 결과: testmalware가 지워지고 다음 단계로 간다. 취소하면 "앱이 아직 남아 있습니다." 안내가 나온다.
- [ ] **5단계 마무리**
  - 방법: 완료 화면에서 확인을 누른다.
  - 기대 결과: 검사 화면으로 돌아가고 목록에서 testmalware가 없다.
- [ ] **삭제 실패 안내**
  - 방법: 권한을 끄지 않고 삭제를 시도해 본다.
  - 기대 결과: 실패 안내와 긴급 전화 버튼이 보인다.

## 6. 인터넷 차단과 재부팅 유지

- [ ] **차단 켜기**
  - 방법: testmalware를 다시 설치하고 통신 감시 탭 또는 앱 상세에서 인터넷 차단을 켠다. VPN 허용 창이 뜨면 확인한다.
  - 기대 결과: 상단에 VPN(열쇠) 표시가 나타나고 차단 상태가 표시된다. 다른 앱 인터넷은 정상이다.
- [ ] **차단 효과**
  - 방법: testmalware 또는 차단한 앱을 실행해 인터넷을 쓰는 기능을 시도한다.
  - 기대 결과: 해당 앱만 통신이 안 된다.
- [ ] **재부팅 후 유지**
  - 방법: 휴대폰을 재부팅하고 잠금 해제 후 앱을 열지 않은 채 차단 앱을 다시 시도한다. 이후 앱을 열어 상태를 본다.
  - 기대 결과: 차단이 유지되고(항상 켜진 VPN 설정 또는 부팅 시 자동 시작), 앱의 차단 목록도 그대로이다.
- [ ] **차단 해제**
  - 방법: 차단을 끈다.
  - 기대 결과: 해당 앱 통신이 다시 된다.

## 7. 데이터 사용량

- [ ] **권한 안내**
  - 방법: 통신 감시 탭을 연다. 사용 정보 접근이 꺼져 있으면 안내가 나온다.
  - 기대 결과: 설정으로 이동하는 버튼이 있고, 허용 후 돌아오면 목록이 나온다.
- [ ] **사용량 표시**
  - 방법: 브라우저로 영상 등을 잠시 본 뒤 통신 감시 탭을 새로 고친다.
  - 기대 결과: 앱별 사용량이 큰 순서로 나오고, 위험 앱은 위험도 색으로 표시된다. 목록의 앱을 누르면 상세 화면으로 간다.

## 8. 기록 탭

- [ ] **설치 기록**
  - 방법: testmalware를 설치하고 기록 탭을 연다.
  - 기대 결과: 설치 항목이 시간과 함께 맨 위에 추가된다.
- [ ] **삭제 기록**
  - 방법: testmalware를 삭제하고 기록 탭을 연다.
  - 기대 결과: 삭제 항목이 추가된다. 항목을 누르면 앱 상세(남아 있는 경우)로 이동한다.
- [ ] **재시작 후 유지**
  - 방법: 앱을 완전히 종료했다 다시 연다.
  - 기대 결과: 기록이 그대로 있다.

## 9. 새 앱 설치 알림

- [ ] **알림 권한 확인**
  - 방법: 설정 > 앱 > 알림에서 이 앱의 알림이 켜져 있는지 확인한다.
  - 기대 결과: 켜져 있다.
- [ ] **15분 내 알림**
  - 방법: 앱을 한 번 열어 둔 뒤(작업 예약), 새 앱(testmalware 등)을 설치하고 앱을 닫은 채 최대 15분(배터리 최적화에 따라 더 걸릴 수 있음) 기다린다.
  - 기대 결과: 새 앱이 설치되었다는 알림이 온다. 3개 이상 설치하면 묶음 알림이 된다.
- [ ] **알림 누르기**
  - 방법: 알림을 누른다.
  - 기대 결과: 앱이 열리고 기록 탭이 보인다. 앱이 이미 켜져 있을 때도 기록 탭으로 이동한다.

## 10. 자동 업데이트

- [ ] **새 버전 알림**
  - 방법: 이전 버전 앱을 설치한 상태에서 저장소에 새 태그(예: `vX.Y.Z`)를 올려 릴리스 워크플로가 끝나기를 기다린 뒤 앱을 연다(또는 설정에서 업데이트 확인).
  - 기대 결과: 새 버전이 있다는 안내가 앱 안에 나온다.
- [ ] **내려받기와 설치**
  - 방법: 안내에서 업데이트를 누르고, 필요하면 출처를 알 수 없는 앱 설치를 허용한 뒤 시스템 설치 화면에서 설치한다.
  - 기대 결과: 내려받기가 끝나고 설치 화면이 열리며, 설치 후 설정 화면의 버전이 새 버전이다. 기존 설정과 차단 목록이 유지된다(서명이 같아 덮어쓰기됨).
- [ ] **릴리스 파일**
  - 방법: GitHub 릴리스 페이지를 확인한다.
  - 기대 결과: `phishguard-vX.Y.Z.apk`와 `.apk.sha256`이 있고, 내려받은 APK의 SHA-256과 일치한다.

## 11. 다크 모드

- [ ] **다크 전환**
  - 방법: 시스템 설정에서 다크 모드를 켜고 앱을 연다(안내 화면, 검사, 통신 감시, 기록, 설정, 앱 상세, 삭제 화면 모두).
  - 기대 결과: 배경이 어두운 남색 계열이고 글자가 또렷하다. 흰 바탕에 흰 글자나 어두운 바탕에 어두운 글자로 안 보이는 곳이 없다.
- [ ] **위험도 색**
  - 방법: 위험도 높음, 중간, 낮음 배지와 삭제 단계 표시를 본다.
  - 기대 결과: 배지 글자와 배경이 모두 읽힌다.
- [ ] **상태 표시줄**
  - 방법: 라이트와 다크에서 상단 상태 표시줄을 본다.
  - 기대 결과: 시계와 아이콘이 배경과 구분된다.
- [ ] **실행 중 전환**
  - 방법: 앱을 켜 둔 채 빠른 설정에서 다크 모드를 껐다 켠다.
  - 기대 결과: 앱이 새 테마로 다시 그려지고 데이터(검사 결과 등)가 유지된다.

## 12. 큰 글자 200%

- [ ] **글자 크기 설정**
  - 방법: 설정 > 디스플레이 > 글자 크기 및 스타일에서 가장 크게 하고, 개발자 옵션 또는 접근성에서 가능하면 200% 가까이 키운다. 화면 크기(표시 크기)도 크게 해 본다.
  - 기대 결과: 앱을 다시 열었을 때 모든 화면에서 글자가 잘리지 않고 줄바꿈된다.
- [ ] **안내 화면**
  - 방법: 큰 글자 상태에서 안내 1~3쪽을 본다.
  - 기대 결과: 내용이 스크롤되고 "다음", "건너뛰기", "시작하기" 버튼이 화면 밖으로 밀려나지 않는다.
- [ ] **주요 화면**
  - 방법: 검사 목록, 앱 상세, 삭제 5단계, 설정, 하단 탭을 본다.
  - 기대 결과: 버튼 글자와 탭 이름이 읽히고 눌러진다. 겹치거나 잘려서 못 읽는 글자가 없다.

## 13. TalkBack 간단 점검

- [ ] **켜기**
  - 방법: 설정 > 접근성 > TalkBack을 켠다.
  - 기대 결과: 앱 화면을 한 번 탭하면 해당 요소를 읽는다.
- [ ] **안내 화면**
  - 방법: 안내 1쪽에서 오른쪽으로 쓸며 읽는다.
  - 기대 결과: 각 쪽 제목이 "제목"으로 읽히고, 점 표시는 "1 / 3 페이지"처럼 한 번에 읽힌다. 전화 버튼은 번호와 기관 이름이 읽힌다.
- [ ] **검사 목록과 배지**
  - 방법: 검사 탭에서 목록 항목을 읽는다.
  - 기대 결과: 앱 이름과 위험도(예: "위험 높음")가 함께 읽힌다. 장식용 아이콘은 읽히지 않는다.
- [ ] **하단 탭과 버튼**
  - 방법: 하단 탭과 주요 버튼을 이동한다.
  - 기대 결과: 탭 이름과 선택 여부가 읽히고, 이름 없는 버튼("버튼"만 읽힘)이 없다.
- [ ] **삭제 단계 안내**
  - 방법: 삭제 화면에서 단계 표시와 결과 문구를 읽는다.
  - 기대 결과: "완료", "진행 중" 같은 상태가 읽히고, 결과 문구가 바뀔 때 자동으로 안내된다.
- [ ] **끄기**
  - 방법: TalkBack을 끈다.
  - 기대 결과: 일반 터치 조작이 돌아온다.
