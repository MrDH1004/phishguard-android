# 피싱앱 검사기 (PhishGuard)

보이스피싱 피해로 폰에 몰래 설치된 악성앱을 찾아 **증거를 남기고 → 인터넷을 끊고 → 지우는** 안드로이드 앱입니다.
검사는 인터넷 없이 기기 안에서만 동작하며, 개인정보를 외부로 보내지 않습니다.

> 급하면 먼저: 비행기 모드 → **112 / 금감원 1332**에 신고하고 은행에 지급정지 요청 → **KISA 118**(무료 악성앱 점검)

## 기능
| 기능 | 내용 |
|---|---|
| 앱 전체 조사 | 설치된 모든 앱 나열 (아이콘 숨긴 앱 포함, 시스템 앱 토글) |
| 권한 조사 | 문자·통화기록·전화·연락처·접근성·기기관리자·다른 앱 위에 그리기·알림 접근·앱 설치 권한 |
| 최근 설치 | 설치 시각과 출처(Play 스토어 / 기타 스토어 / APK 직접 설치)로 필터 |
| 의심 점수 | 출처·설치 시기·아이콘 숨김·위험 권한·기관/금융사 사칭 이름을 합산해 높음/중간/낮음 표시 (`scan/RiskRules.kt`) |
| 인터넷 차단 | 의심 앱만 골라 인터넷을 끊음 (로컬 VPN이 해당 앱 패킷만 받아 버림, 다른 앱은 영향 없음) |
| 데이터 사용량 | 앱별 Wi-Fi/모바일 송수신량 (24시간/7일/30일) |
| 증거 저장 후 삭제 | 증거 ZIP(APK·권한·설치정보·사용량) 저장 → 차단 → 기기관리자/접근성 해제 안내 → 삭제 → 재검사 |
| 자동 업데이트 | GitHub Releases 확인 → SHA-256·서명 인증서 검증 후 설치 |

통신 상대 IP·국가는 이 앱에서 보여주지 않습니다. 필요하면 오픈소스 앱 [PCAPdroid](https://github.com/emanuele-f/PCAPdroid)를 함께 쓰세요 (VPN은 한 번에 하나만 켜집니다).

## 설치
[Releases](../../releases/latest)에서 `phishguard-vX.Y.Z.apk`를 받아 설치합니다 ("출처를 알 수 없는 앱" 허용 필요). Android 8.0 이상.

## 개발
```bash
./gradlew assembleDebug testDebugUnitTest
```
- `:app` 본 앱, `:testmalware` 테스트용 가짜 의심앱("검찰청 사건조회" — 기기관리자·접근성·SMS 권한, 아이콘 숨기기)

## 배포 (자동)
`v*` 태그를 push하면 GitHub Actions가 APK와 `.sha256`을 Release에 올리고, 설치된 앱이 실행 시 새 버전을 감지해 업데이트를 안내합니다.
```bash
git tag v1.0.1 && git push origin v1.0.1
```
## 서명
개인용이라 서명 키(`signing/phishguard-public.jks`, 비밀번호 `phishguard`)를 저장소에 포함했습니다. 어디서 빌드해도 같은 서명이라 업데이트가 이어지고, 따로 관리할 Secrets가 없습니다.
키가 공개돼 있으므로 이 저장소 Releases가 아닌 곳에서 받은 APK는 설치하지 마세요.
